# Makar technical proof fixture

This directory contains the SKIDS-011 deterministic runtime fixture for Makar.

It proves:

- `fox_cartoon` rig compatibility;
- reusable structured SVG parts;
- blink and gaze variants;
- point and talk acting poses;
- all semantic mouth visemes;
- deterministic reuse by the local renderer.

This is **not** a replacement for approved production character art.
It must not be treated as the final visual identity reference.

Production palette/proportion/wardrobe/identity comparison remains an explicit
human approval step. Character QA may therefore report reference warnings until
approved production reference assets are attached.
